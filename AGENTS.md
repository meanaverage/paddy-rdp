# Component changes

Preserve the host boundary described in README.md. Native SSH access must go through SshHost with a window owner; never introduce direct access to the host's session registry. Keep stored profile keys, bounded ABI shapes, tagged UTF-16/non-finite values, clipboard restrictions, and each core's state-loss policy compatible.

Use independent fixtures for behavior changes. Do not replace historical parity oracles with expected values generated by current code. Update snapshot provenance deliberately when changing the shared SDK. Host integration checks must accompany host interface changes.
